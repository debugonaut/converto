# Converto 1.1.0 desktop update and mobile preview work

Desktop source commit: `1eb9d067c105dec62e936a8911b052df34d0d14f`.
[Native run 41441688835](https://github.com/debugonaut/converto/actions/runs/41441688835)
passed on macOS, Windows and Linux. [PR #1](https://github.com/debugonaut/converto/pull/1)
was merged after user approval. All desktop packages use version 1.1.0, build 2.

Downloaded packages matched native audit hashes. Both Mac variants passed deep
signature validation and native architecture inspection; Info.plist reports
1.1.0/2. Windows embeds 1.1.0 and passed its native runtime/first-frame checks.
Linux passed portable and Debian startup/picker/engine checks; the Debian
package reports `1.1.0~preview.2`.

Local desktop downloads were replaced atomically, and the existing working
Mac app path was replaced with the verified Apple Silicon app. Three older
1.0.0 app copies were moved to Trash. The new Mac app launched and remained
running. Native UI inspection was unavailable because Computer Use permission
was not enabled; this is separate from the Flutter render and native CI checks.

Android release preview APKs built for ARM64, ARMv7 and x86-64 after aligning
legacy Android library compilation with API 36. Package audits passed engine,
architecture, signature and 16 KB alignment checks. Manifest minSDK is 24 and
targetSDK is 36, with no INTERNET or broad storage permissions. The apps use
the Android debug signing key as developer previews. Physical-device import,
export and backgrounding checks remain pending.

iOS now has a runner, UIScene initialization and native Files import/export/
opening bridge, using app-private data/results and the shared mobile UI. Local
Swift syntax checks and 168 shared Flutter tests passed (one platform skip).
Native simulator/device builds are validated separately by the iOS workflow.
Developer signing and TestFlight/App Store publication remain separate work.
