# Converto 1.1.0 (build 2)

- Multiple images converted to PDF now create one combined document by default,
  following the file list order. Separate PDFs remain available.
- Create scanned PDF accepts PDFs, images, and supported document formats.
  Apply contrast and brightness across every page, choose color/grayscale/black
  and white, compare with the original, and select the export resolution.
- Scanned output preserves displayed page dimensions and orientation, contains
  page images, and does not retain selectable/searchable text.
- Shared desktop and phone layouts support the new tool, combined output names,
  cancellation, per-input errors, and local-only processing.
- Existing local PDF export and CLI improvements are included in the current
  source snapshot. Platform packages share version 1.1.0 and build number 2.

Desktop builds are produced on their native macOS, Windows, and Linux runners.
Developer previews retain their existing signing status. Runtime conversion
does not require a network connection.
