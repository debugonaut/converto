Conversion and editing capabilities

Core toolset available across macOS, Windows, Linux, Android, and iOS from a single local application.

Image Studio

Interactive cropping with preset aspect ratios (1:1, 4:3, 16:9), orthogonal 90-degree rotations, horizontal/vertical flips, and quality-controlled compression with estimated file size output.

PDF Manipulator

Combine multiple disparate PDFs into a single document, split documents by custom page intervals (e.g. 1-4, 7, 9-12), extract individual pages, and render PDF pages to high-DPI bitmap images.

Text Watermarking

Apply customizable diagonal or centered text watermarks to any PDF document. Configure opacity, angle, font scale, and positioning to protect drafts or mark confidentiality.

Batch Queue

Drop dozens of files into a conversion queue simultaneously. The engine processes items across background isolates, leveraging multi-core hardware without freezing the user interface.

Local architecture and privacy

How Converto guarantees that data never leaves your machine.

No Remote Network Endpoints

The application manifests on macOS, Windows, Linux, Android, and iOS contain zero cloud API keys, zero analytics SDKs, and zero upload endpoints. The app functions fully in air-gapped environments or with network adapters disabled.

Device-Managed Storage

Converted output files are written directly to your local file system under ~/Documents/Converto/. Temporary processing buffers are purged from memory immediately upon job completion.

Open Source and Auditable

Every line of conversion logic, UI code, and build configuration is published under the Apache 2.0 license. Anyone can inspect, build from source, or audit the binaries.
